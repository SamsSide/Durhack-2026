## Verbatim briefs

### P1 Best Use of ElevenLabs

Deploy natural, human-sounding audio with ElevenLabs. Create realistic, dynamic, and emotionally
expressive voices for any project, from interactive AI companions to narrated stories and
voice-enabled apps. ElevenLabs will empower you to build rich, immersive experiences without the
need for actors or complex audio production, using simply the power of AI. Integrate fully
autonomous audio experiences into your hack with ElevenLabs and give your project a voice, along
with giving your team the chance to win some wireless earbuds!

### P2 Best Use of Gemini API

It's time to push the boundaries of what's possible with AI using Google Gemini. Check out the
Gemini API to build AI-powered apps that make your friends say WHOA. Understand language like a
human and build a chatbot that gives personalized advice. Analyze info like a supercomputer and
create an app that summarizes complex research papers. Generate creative content like code,
scripts, music, and more.

### P3 Best Use of Entire

Entire is the Git forge for agent-human collaboration. From syncing your sessions and prompts to
your Git history, to hosting code and replacing the Pull Request with Trails, Entire are
reimagining code hosting and collaboration for the agent era.

Ready to build faster with AI without burning through tokens or losing context? This challenge is
all about building smarter AI workflows. To qualify, your project should leverage as many of
Entire's core capabilities (Sessions, Graph, and/or Brain) as possible. Your project should lean
on Sessions for context and memory and entire-graph for codebase mapping:

- Sessions (Shared Memory): Save your AI agent sessions as instant checkpoints and push them to
  your team. Teammates or other agents can jump in instantly and pick up right where you left off
  with zero context loss.
- Graph (Codebase Mapping): Generate a visual map of how your codebase fits together. Using
  entire graph search instead of letting agents blindly search files to cut token usage by up to
  71%.
- Brain (Persistent Reasoning): Combine your session data and Graph insights into persistent
  project knowledge. Agents can query past decisions and architectural lessons through the CLI or
  MCP so they don't repeat mistakes or undo working code.
- Trails (Code review): Assign you or a teammate's agent a task via Trail (Entire's issue/PR
  combo primitive), the agent works on it, and then let your agent review the code change: does
  the code change match the intent? Should it merge?

We're looking for teams that use Entire to create seamless human-AI collaboration, maintain clean
code history, and show measurable token efficiency.

### P4 Best Use of Solana

Harness Solana's core advantages like blazing fast execution and near-zero transaction costs to
make your hackathon ideas become real world projects. Create a game, social app, or consumer
product that relies on instant, high-frequency transactions. Design a sophisticated trading,
lending, or decentralized exchange (DEX). Build a prototype for supply chain, identity, or
payments that can handle massive, real-world volume.

### P5 Best Use of Tiger Data

Tiger Data extends PostgreSQL to give student developers an ultra-fast foundation for real-time
data, time-series metrics, and complex analytics. Standard SQL Power: query massive datasets
using the SQL you already know. Unified Data Stack: store relational user profiles and
high-frequency metric streams side-by-side in a single database. Instant Dashboards: serve
lag-free, real-time frontend charts using pre-computed Continuous Aggregates. 90%+ Data
Compression: store millions of events on free-tier cloud instances. Whether you're building
real-time IoT monitoring, AI-driven analytics dashboards, or financial prediction engines, show
us how Tiger Data powers your project. The team that demonstrates the most innovative,
impactful, and performance-driven use of Tiger Data wins.
